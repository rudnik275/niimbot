# Личная библиотека наклеек

Пользователь просит придумывать дизайн и текст по короткому описанию, хранить идеи и переиспользовать похожие наклейки в будущих сессиях. Проект начат 2026-09-14.

## Носитель и стиль

- Принтер NIIMBOT B1 (модель уточнил пользователь).
- В принтер загружены парные наклейки: каждая 40×15 мм, две вплотную по направлению подачи; промежуток только между парами (подтверждено пользователем по фото). Страница печати должна учитывать пару, а не одну половину.
- Для крепежа главное — сразу узнать предмет по рисунку и прочитать крупный размер.
- На первой наклейке только «M3×6» и изображение винта с потайной головкой. «RN», «потай», «чёрный» — описание предмета, не печатаемый текст. Значение RN не уточнялось; шлиц на рисунке не показан.
- Чёрное на белом, без рамок и мелких подписей. Схематичная пиктограмма, не размерный чертёж.
- Первые макеты не считаются утверждённым стилем, пока пользователь не оценил результат.

## Идеи пользователя

- Ящички с крепежом: рисунок конкретного типа винта/болта и размер; одна семья шаблонов для разных размеров.
- Еда: рисунок продукта, название, срок годности или дата. Даты и сроки получать от пользователя; не придумывать их по типу продукта.

## Дизайн первой серии

Основа — пользовательский приоритет «размер + узнаваемая картинка». Из refero-design/references/icons.md взяты единый вес пиктограмм и проверка на малом размере; из typography.md — нейтральный жирный шрифт для быстрого чтения. Никакой веб-интерфейс не создаётся.

Решения: крупный Arial Bold; чёрный силуэт слева с белыми канавками резьбы; широкая плоская головка с коническим низом; короткий тупой стержень; достаточные поля. Геометрический оригинал воспроизводится скриптом, поэтому новые размеры не требуют повторной генерации картинки. Реальная читаемость и поля проверяются пробной печатью после определения модели.

## Уточнение художественного направления

Пользователь требует красивые, выразительные, суперминималистичные и понятные наклейки. Новые иллюстрации создавать через последнюю доступную GPT Image; текст и подготовку к печати делать отдельно по необходимости. Первую рукотворную пиктограмму заменяем на GPT Image. Для совпадающих предметов переиспользовать одобренную иллюстрацию. Пользователь не спешит; качество важнее скорости. Допустимы и браузер, и установка десктопного приложения — выбрать по возможностям и надёжности.

## Утверждённый дизайн болтов — текущий приоритет

Пользователь передал готовый образец и указал: «вот такой дизайн наклейки для всех болтов только надпись будем менять». Эталон: templates/bolts/master-reference.png; правила переиспользования: templates/bolts/README.md. Эта договорённость заменяет ранний дизайн без рамки и подбор отдельной картинки по типу головки. Теперь для всех болтов один рисунок и одна композиция; меняется крупный размер, подпись «болт» остаётся. Новая генерация для уже утверждённого шаблона не нужна.

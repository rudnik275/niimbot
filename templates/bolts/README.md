# Единый дизайн наклеек для болтов

Утверждён пользователем 2026-09-14. Исходное изображение сохранено без изменений в master-reference.png; это растровый эталон, текст пока не выделен отдельным редактируемым слоем.

Для всех болтов использовать именно этот дизайн и менять только крупную надпись размера (пример M3×6). Сохранять горизонтальный контурный рисунок болта слева, вертикальный разделитель, скруглённую рамку, подпись «болт» с горизонтальными линиями по сторонам, чёрно-белую палитру и композицию. Рисунок одинаков для всех болтов; не заменять его под тип головки, если пользователь отдельно не попросит.

Новые варианты сохранять отдельно, оставляя эталон неизменным. Не генерировать заново весь дизайн ради другого размера. Шаблон заменяет предыдущие варианты крепежа v1/v2. Физическая печать этого дизайна пока не проверена. Размер одной наклейки 40×15 мм, текущая лента — две наклейки вплотную в паре, промежутки только между парами.

# Подключение NIIMBOT

Проверено 2026-09-14. Модель B1 сообщил пользователь. Соединение по Bluetooth через Chrome/NiimBlue проверено: B1 подтвердил завершение одного тестового задания. Пользователь разрешил установить десктопное приложение, если это даст преимущество перед браузером.

Кандидат для совместной работы: Mac → Chrome → NiimBlue → Bluetooth → NIIMBOT. NiimBlue заявляет поддержку Bluetooth и USB; совместимость зависит от модели. Первичное разрешение браузера/macOS или выбор принтера могут потребовать действия пользователя. После подключения проверить определённую модель, разрешение и доступную ширину. Начать с одного экземпляра.

Источники:
- NiimBlue: https://github.com/MultiMote/niimblue — поддержка соединений, Chrome, импорт и экспорт, предпросмотр.
- Приложение: https://niim.blue
- Официальный Mac-клиент: https://www.niimbot.com/au/downloadCenter?hideCategoryList=true&showDetail=true&system=macOS — macOS 12+, поддерживает ограниченный список моделей. На дату проверки: B1, B21, B21S, B21-C2B, B3S_P, K3, M2_H, B1 Pro, M3, EP3M, B3S, B21_Pro, B31.

Не считать наличие USB-разъёма доказательством печати через USB. Не обещать автоматическую печать до проверки соединения и первой наклейки.

Для импорта: label-v2.png — белый фон, точные пропорции 40:15; в редакторе задать эти физические размеры и сохранить пропорции картинки. Уменьшение под печатную область и поворот зависят от модели. label-v2-203dpi.png — двуцветный черновик 320×120, а не подтверждённый нативный формат устройства.

## Подготовка теста

NiimBlue открыт в Chrome. Макет v2 импортирован через нативное окно выбора файла macOS (программный setFiles недоступен без расширенного доступа к file URLs; нативный импорт работает). В предпросмотре проверены рисунок и надпись. Настройки: 40×15 мм, 8 точек/мм (320×120), направление Top, B1, WithGaps, плотность 3, 1 экземпляр, смещения 0. B1 подключён; один тест отправлен и подтверждён ответом In_PrintEnd. См. PRINT_LOG.md: после печати есть ошибка чтения RFID, требующая учёта при работе с расходниками.

## Важно: тест отклонён

Первый профиль 40×15 неверен для текущей парной ленты. Две наклейки идут вплотную; нужен профиль всей пары. Не повторять профиль первого теста. Качество и центрирование отклонены пользователем. Проверяем официальное приложение, не считая вину браузера доказанной.

## Официальный Mac-клиент

2026-09-14 установлен /Applications/NIIMBOT.app, bundle com.niimbot.print, фактическая версия 4.2.4. Скачан по кнопке официального центра загрузок: https://oss.niimbot.com/print/mac/NIIMBOT-4.2.4-202608131123.dmg (страница при этом подписана V4.2.5). Подпись проверена codesign --verify --deep --strict. NiimBlue отключён от B1 для освобождения Bluetooth.

Приложение автоматически обновилось до 4.2.5; запуск и главная страница проверены. Окно входа можно закрыть; проверка подключения начата без принятия пользовательского соглашения и без входа.

Проверка интерфейса 4.2.5: B1 пока не обнаружен, поиск показывает просьбу включить устройство или подключить комплектным data-кабелем. Пользователю предложено подключение USB. При двух попытках открыть Create a label (основная кнопка и стрелка меню) приложение показало стартовый экран NIIMBOT и затем вернулось на Home; шаблон создать пока не удалось. Причина не установлена, не считать нативный клиент уже рабочим решением. Дополнительных отпечатков не было.

После сообщения «+» повторно проверен IOUSB через ioreg: B1/USB-serial отсутствует в дереве USB (видны хабы, Brio 100, Logitech Receiver, Varmilo). Запрошена проверка data-кабеля/прямого порта. При автоматизированном вводе в нативное приложение процесс действительно перезапускается: до Tab/Return PID 59523, после PID 59649; сбой повторяется и при координатном клике. AX-click по image-элементу не открывает диалог. Не установлено, относится ли сбой к NIIMBOT или механизму управления CUA; для различения нужна проверка обычного ручного клика пользователем.

# Бирка — наклейки для NIIMBOT

Локальное веб-приложение для печати маленьких наклеек на термопринтере NIIMBOT B1
(и других моделях, которые понимает [niimbluelib](https://github.com/MultiMote/niimbluelib))
прямо из Chrome по Bluetooth. Для ящиков с болтами, светодиодами, микросхемами,
инструментом.

Шаблон одной наклейки: **пиктограмма слева · разделитель · крупный текст**, под ним по
желанию **мелкая подпись**. Текстовый блок центрируется по вертикали (вместе с подписью
или один). Стиль один на все наклейки: Golos Text, без рамок и украшений — ящик с
наклейками должен выглядеть одним набором. Пиктограммы — векторная библиотека (крепёж,
электроника, инструмент, разное); болт собирается из параметров: головка, резьба и вид
сверху со шлицем.

Превью — это ровно тот битмап, который уедет в принтер: холст в точках принтера
(8 точек/мм), бинаризация до чистого чёрно-белого, увеличение без сглаживания.

## Настольное приложение

```sh
npm install
npm run app:install
```

Собирает `Бирка.app` (Electron, без подписи), кладёт в `~/Applications` и делает алиас на
рабочем столе. Открывается двойным кликом; при первом подключении macOS спросит разрешение
на Bluetooth. Выбор принтера — своё окно приложения (у Electron нет встроенного диалога);
«снова к B1-…» подключается к прошлому принтеру без вопросов. Обновить после правок кода —
снова `npm run app:install`. Отладка оболочки на живом dev-сервере: `npm run dev`, затем
`npm run app:dev`.

## Запуск в браузере

Нужны Node 22+ и Chrome (или Edge). Web Bluetooth работает только на `http://localhost`
или `https://`.

```sh
npm install
npm run dev
```

Открыть <http://127.0.0.1:5173/> в Chrome. Включить принтер, нажать **Подключить**,
выбрать `B1-…` в диалоге браузера.

Production-сборка в `dist/` (статика, можно положить на любой https-хостинг или
раздавать `npx vite preview`):

```sh
npm run build
```

Тесты (раскладка, лента, бинаризация, поворот, библиотека иконок):

```sh
npm test
```

## Как пользоваться

1. **Принтер.** Верхняя полоса: подключение, заряд, ширина головки, формат ленты. После подключения
   читается RFID рулона: штрихкод ленты, сколько наклеек осталось. Если штрихкод
   известен — формат выбирается сам; если нет — кнопка «запомнить как …» привязывает
   его к текущему формату навсегда (хранится в localStorage).
2. **Формат.** По умолчанию `40×15 парные (T40×15/2R)`: две наклейки 40×15 мм идут
   вплотную по подаче, зазор только между парами, поэтому принтер всегда печатает
   **пару** как одну страницу 40×30 мм (320×240 точек). Другие форматы — в списке,
   свой добавляется кнопкой «+ формат».
3. **Наклейки.** Левый сайдбар — верхняя наклейка пары, правый — нижняя. В каждом всё
   своё: крупный текст, мелкая подпись, пиктограммы по категориям с поиском (у болта ещё
   ряды параметров) и список недавних. «Как верхняя» в правом сайдбаре печатает первую на
   обе; «⇅ поменять» под превью меняет их местами. `x` между цифрами сам становится `×`.
4. **Печать.** Плотность 1–5 (у B1 по умолчанию 3), число пар. В «калибровке» — сдвиг
   по X/Y в точках (1 точка = 0,125 мм), порог бинаризации и **тест**: рамка в 1 мм
   от края каждой наклейки и крест по центру — по нему подбирается сдвиг, если принтер
   печатает не по центру.
5. **Недавние.** Всё напечатанное (и сохранённое звёздочкой) остаётся чипами внизу
   каждого сайдбара: клик подставляет наклейку в эту половину.

Кнопка **PNG** под превью скачивает точный битмап страницы — полезно для сравнения
с отпечатком или печати через другой клиент.

## Устройство

```
src/
  model/      media.ts (форматы ленты, страница = единица подачи), label.ts (что на наклейке)
  icons/      библиотека пиктограмм: types (пути, помощники), fasteners (параметрический болт …),
              electronics (схемные символы), tools (инструмент/разное), index (реестр, поиск)
  render/     layout.ts (чистая раскладка, тестируется без DOM), draw.ts (canvas),
              raster.ts (бинаризация), fonts.ts
  printer/    client.ts — обёртка над @mmote/niimbluelib: подключение, RFID, печать
  state.ts    сигналы Preact + localStorage
  ui/         TopBar (принтер, лента, формат), LabelSidebar ×2 (текст, IconPicker, Library),
              Bed (превью с линейками), PrintPanel, LogPanel, BlePicker (выбор устройства в Electron)
electron/     main.cjs (окно, проброс списка Bluetooth-устройств), preload.cjs (мост window.birka)
build/        icon.svg — исходник иконки приложения
scripts/      install-app.sh — сборка .app и установка в ~/Applications
docs/
  CONTEXT.md  живой контекст проекта: термины, решения, что проверено
  adr/        архитектурные решения
  reference/  утверждённый пользователем эталон дизайна болта
```

## Ограничения и заметки

- Печать через браузер требует Chromium; Safari и Firefox без Web Bluetooth.
- Быстрое переподключение без диалога («снова к B1-…») опирается на
  `navigator.bluetooth.getDevices()`; в старых Chrome его нужно включить во флаге
  «Use the new permissions backend for Web Bluetooth».
- Принтеры с направлением печати `left` (D110 и подобные) поддержаны поворотом
  страницы; проверено тестом против кодировщика библиотеки, но не на железе.
- История первой попытки (Codex, сентябрь 2026) — в первом коммите репозитория:
  там журнал подключения B1, фото первого отпечатка и причины отказа от него.

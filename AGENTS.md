# Label workflow

Before designing or reprinting a label, read CONTEXT.md and CATALOG.md. Search the catalogue by object, size and visual type; reuse the closest existing template and change only the requested fields.

Save each variant with its artwork and metadata under labels/. Record user ideas in CONTEXT.md, label variants in CATALOG.md, and actual print attempts in PRINT_LOG.md. Distinguish prepared artwork from physically verified prints; record printing only after device feedback or user confirmation.

For printer setup read CONNECTION.md. Identify the exact hardware model before selecting printable width, DPI, transport or driver. The nominal roll size is not necessarily the printable area.

Create new label illustrations with GPT Image, using the latest available model/tool; preserve original generations and prompts. The user prioritizes beautiful, highly minimal, immediately understandable design over speed. Reuse approved generated artwork when only the wording changes.

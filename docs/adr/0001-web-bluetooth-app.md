# ADR-0001. Браузерное приложение на niimbluelib по Web Bluetooth

Дата: 2026-09-16 · Статус: принято

## Контекст

Нужно печатать на NIIMBOT B1 с Mac без официального приложения. Предыдущая попытка
(Codex) собирала PNG скриптами Python и печатала через niim.blue — чужой редактор
автоматически уменьшил растр до 6/7 и поставил на дробные координаты, отпечаток
забракован. Официальный Mac-клиент 4.2.5 принтер не увидел и падал при создании шаблона.

## Решение

Одностраничное приложение (Vite + Preact + TypeScript), которое само рисует наклейку на
canvas и печатает через `@mmote/niimbluelib` (`NiimbotBluetoothClient` → Web Bluetooth).
Та же библиотека, на которой работает niim.blue, так что транспорт и протокол B1 уже
проверены на этом принтере (первый тест Codex прошёл по нему).

## Последствия

- Только Chromium-браузеры и secure context (`localhost`/`https`). Приемлемо: личный
  инструмент, запускается локально.
- Нет своего кода протокола: обновления niimbluelib подхватываются `npm update`.
  Публичный API 0.46 отличается от main на GitHub (нет `PaperInfo`, событий RFID) —
  обёртка `src/printer/client.ts` изолирует эти различия.
- Вся логика наклейки (раскладка, растр) — наша, поэтому геометрия контролируется до точки.

## Отвергнуто

- Python + BLE (niimprint и подобные): отдельный процесс, нет превью, хуже UX.
- Официальное приложение: закрытое, не работает на этом Mac.
- Импорт PNG в niim.blue: нет контроля масштаба и позиции.

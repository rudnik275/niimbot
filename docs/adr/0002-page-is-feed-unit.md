# ADR-0002. Страница печати = единица подачи; парная лента как слоты

Дата: 2026-09-16 · Статус: принято

## Контекст

Лента T40×15MM/2R: две наклейки 40×15 мм идут вплотную по направлению подачи, зазор для
датчика есть только между парами. В режиме «с зазорами» принтер после страницы проматывает
до следующего зазора. Первый тест печатал страницу 40×15 → напечаталась только верхняя
наклейка, нижняя ушла пустой. Пользователь подтвердил, что почти всегда печатает две
наклейки за раз.

## Решение

`MediaProfile` описывает единицу подачи: `widthMm × heightMm` одной наклейки и `slots` —
сколько их в единице подачи, сверху вниз без промежутков. Страница печати всегда целая:
`cols = width·8`, `rows = height·8·slots`. Каждому слоту — своя `LabelSpec`; переключатель
«одинаковые» печатает первую на все слоты. Обычные рулоны — `slots = 1`.

Формат по умолчанию — `t40x15x2` с привязанным штрихкодом RFID `6971501227736`; при
обнаружении известного штрихкода формат выбирается автоматически, неизвестный можно
привязать к текущему формату (хранится в `localStorage`).

## Последствия

- Интерфейс изначально двухслотовый: вкладки 1/2, подсветка активной половины в превью,
  пунктир разреза между ними.
- Смена формата не теряет содержимое слотов (массив наклеек только дополняется).
- Данные о размере бумаги из принтера (PaperInfo) в текущей библиотеке недоступны;
  размер знаем только из профиля. Если появятся — использовать для предзаполнения формы.

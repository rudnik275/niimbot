# Бирка — правила репозитория

Приложение для печати наклеек на NIIMBOT B1. Перед работой прочитать
[`docs/CONTEXT.md`](docs/CONTEXT.md): словарь, что проверено на железе, открытые вопросы,
принятые решения. Архитектурные решения — `docs/adr/`.

## Трекера задач нет

У репозитория нет remote и нет GitHub-issues. Всё, что нужно помнить между сессиями,
пишется в `docs/CONTEXT.md`: договорённости — в «Решения», не сделанное — в «Открытые
вопросы», непроверенное на принтере — в «Что НЕ проверено». Решение, меняющее архитектуру,
— отдельный ADR.

## Стиль наклейки не настраивается

Одна гарнитура (Golos Text), без рамок, без линий у подписи, без переключателей стиля.
Это решение пользователя: ящик наклеек должен выглядеть одним набором. Не добавлять опции
оформления в `LabelSpec`, даже если попросят «на всякий случай».

## Превью обязано совпадать с отпечатком

Холст рисуется в точках принтера (8/мм) и бинаризуется до кодирования — см.
[ADR-0003](docs/adr/0003-pixel-exact-rendering.md). Любая правка рендера проверяется
`npm test` (раскладка считается чистой функцией без DOM) и глазами на превью.

## Печать никогда не запускать самому

Отправка задания расходует ленту и требует включённого принтера. Агент готовит макет,
печатает человек. Проверка UI — скриншот headless Chrome по `npm run dev`, не печать.

## Библиотека niimbluelib

Смотреть типы установленного пакета (`node_modules/@mmote/niimbluelib/dist/cjs/**/*.d.ts`),
а не исходники с GitHub: в 0.46 нет событий RFID и `PaperInfo`, которые есть в main.

## Команды

```
npm run dev          # веб-версия на http://127.0.0.1:5173
npm test             # 31 тест: раскладка, лента, растр, поворот, иконки
npm run app:install  # собрать Бирка.app в ~/Applications + ярлык на рабочем столе
```
